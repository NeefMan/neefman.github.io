Networked Chess

Playing chess from two separate programs requires a way to pair players and keep their boards in sync. Networked Chess is a Python prototype that pairs two players by username through a TCP relay and displays each player's board with Pygame. It demonstrates socket communication, concurrent connections, and client-side game state without a chess engine or networking framework.

3D Renderer

How does a 3D scene become a 2D image without a graphics library? This project explores that question by implementing a simple 3D rendering pipeline from scratch in JavaScript. Using an interactive wireframe cube displayed on an HTML canvas, it demonstrates the mathematics behind 3D rotation, near-plane clipping, perspective projection, and screen-coordinate transformations.

Leaf Veination Simulation

Leaf veins form branching networks as they grow toward sources of growth signals. This browser-based JavaScript simulation models that process using a simple growth algorithm. Pressing the spacebar generates new attraction points and advances a network of vein points toward them. The result demonstrates how a simple algorithm can produce complex branching vein patterns resembling those found in real leaves.
